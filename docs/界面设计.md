# 界面设计

## 方向

湘潭大学课程项目采用“藏青工作台 + 湘大绛红标识”。以用户提供的校徽建立学校辨识度，内容围绕商品、库存、订单与销售展开。

## 规范

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 湘大绛红 | #9E1B24 | 学校标识、金额强调、重点提示 |
| 藏青 | #18354A | 导航、主要按钮、标题 |
| 正文墨色 | #253746 | 正文、表格内容 |
| 浅灰 | #F3F5F7 | 页面背景 |
| 白色 | #FFFFFF | 表单、列表与图表底色 |
| 边界灰 | #DEE4E9 | 分组、分隔线和输入边框 |

状态单独使用绿色、琥珀色和红色，同时保留文字，避免只依赖色彩。

正文字体使用本地中文无衬线字体：苹方、微软雅黑、思源黑体等系统回退；登录页主标题使用宋体风格，呼应学校标识，数字使用等宽数字特性。正文 14px，表格 13px，辅助标注采用 11–12px。无外部字体请求。

## 布局

方案 A：学校标识位于深色侧栏顶部，主要操作和数据区左对齐。

```text
┌──────────┬────────────────────────────────────┐
│ 校徽     │ 面包屑                    管理员   │
│ 湘潭大学 ├────────────────────────────────────┤
│ 系统名称 │ 页面标题                  主操作   │
│          │ 指标区 / 筛选条件                  │
│ 业务导航 │                                    │
│          │ 图表 / 数据表格 / 编辑表单         │
│ 基础资料 │                                    │
└──────────┴────────────────────────────────────┘
```

方案 B：横向主导航，让表格拥有更大宽度；在现有七个入口及窄屏下，需要更多折叠与跨页定位。

采用方案 A，延续用户已经熟悉的左侧工作流。登录页分为品牌介绍和账号登录两区，移动端保留校徽与简洁登录表单。指标采用连续分栏结构，降低重复卡片边框带来的视觉负担。

## 复核

通用的英文大写前缀、装饰性编号与彩虹指标图标对这个中文课程项目帮助有限，因此改为学校标识、明确的中文标题与统一的状态语义。重点放在校徽、销售数字和主操作，图表颜色服务数据辨识。

校徽文件直接复制用户附件，保持原始 PNG、透明度、色彩和长宽比。白色圆形承托仅用于深色背景下的识别，图像自身不重绘、不裁切。

实现继续使用 Flask、Jinja2 和本地 Bootstrap / ECharts。数据库查询、成交金额、库存事务、取消逻辑及 CSRF 保持原有行为。页面检查覆盖桌面、移动端、搜索分页、订单预估、焦点和减少动画设置。

## 验证

已在真实本地 MySQL 数据上检查登录、退出、密码显隐、仪表盘、商品搜索与分页、商品表单、订单列表、历史详情、下单表单、基础资料和销售统计。桌面及 390/320 像素窄屏布局均已核对，已检查的手机端仪表盘与订单表单没有整体横向溢出，长金额完整显示。表格使用可横向滚动的独立容器保留完整字段。移动导航可以展开、跳转，并使用 Escape 收起。

订单表单中，Chai 两件、折扣率 0.1、运费 8.50 显示 40.90；再增加三件 Chang 后显示 97.90，移除第二条后恢复 40.90。浏览器检查期间未提交新的业务订单。原有 26 项真实 MySQL 核心测试通过，浏览器未发现 warn/error 日志。
